# Что сделано с самого начала

В проекте уже был базовый FastAPI-сервис для общения с GigaChat:

- маршруты `/health`, `/question` и `/extract-pdf`;
- сервис `GigaChatService` с OAuth и обменом токеном;
- Pydantic-схемы для вопросов и ответа;
- настройка подключения через `.env` и `config.py`.

Для работы с загружаемым файлом в проект были добавлены следующие элементы:

- новый маршрут `/extract-pdf`, который принимает `UploadFile` и возвращает структурированный JSON вида `{"categories": {...}}`;
- схема `CategoriesExtractionResponse` для строгой категории/списка значений;
- локальный текстовый парсер PDF через `pypdf`;
- универсальный промпт `build_categories_prompt()` внутри `GigaChatService`, который фиксирует список категорий и просит модель вернуть только JSON;
- функцию `normalize_categories_payload()` для нормализации ответа модели в словарь `categories`;
- fallback-логика и локальная эвристика извлечения из текста документа, чтобы не получать пустой ответ;
- поддержка DOCX через прямой разбор XML-файла `word/document.xml` внутри `.docx`.

Также были обновлены:

- `README.md` с примером использования пути `/extract-pdf`; 
- `tests/test_api_pdf.py` как регрессионный тест роута загрузки файла и JSON-схемы.

Итог: сервис теперь умеет принимать документ как файл, извлекать из него текст, передавать единый промпт через код, а затем возвращать предсказуемый объект категорий вместо свободного текстового ответа.
